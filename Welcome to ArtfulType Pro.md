# Welcome to ArtfulType Pro

Start writing your next masterpiece.

## Features

- **Writer mode** — live Markdown editing
- **Dracula theme** — beautiful dark palette
- Native file I/O with recent files
- Auto-save support

### Keyboard Shortcuts

| Action | Key |
| --- | --- |
| Bold | Ctrl+B |
| Italic | Ctrl+I |
| Code | Ctrl+K |
| H1–H6 | Ctrl+1–6 |
| Blockquote | Ctrl+Q |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Toggle Mode | Ctrl+M |

#### Live triggers in Writer Mode

> Type `- ` → bullet list · `1. ` → numbered · `> ` → blockquote
> Type `# ` / `## ` / `### ` → headings
